8. **Security, assumptions and limits.** The binary reads fixed public table names only, no package/key/witness inputs. Loading opens one descriptor, checks its owner/private regular mode/exact size, physically bounds reads to exact canonical size plus one EOF-check byte, hashes the same received bytes during canonical decoding, and requires exact vector/EOF/digest. Public construction retains one weight vector; batch-inversion product scratch is included in64MiB live structural/32MiB retained table accounting. No N-root vector is retained. Public coefficients and basis scalars use recorded SHA256 little-endian reduction mod Fr, with zero mapped to one; this is full-width deterministic public data, not a uniform cryptographic sampler or production proof RNG. Engine structural preflights do not promise OOM recovery, allocator usable-size/RSS bounds or constant-time behavior. Diagnostic callback/allocator/timer behavior is outside engine guarantees. The accepted comparator receives canonical sorted rows with zero paid normalization at the real callsite; Fast pays its own conversion. Separating field/group work stores diagonal products and does not reproduce the original interleaved whole product call. Synthetic sparse-basis group work is labeled separately from product encoding/material preparation. Actual private credential supports and end-to-end retained material remain unmeasured.
