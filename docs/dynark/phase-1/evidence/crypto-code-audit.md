## Complete current computation

1. `harness/src/registry.rs::input` constructs synthetic TBS/signature/action/path input; witness probe preserves separate near/mid/far/serial fixture trees. Existing source signs locally using synthetic fixture keys; no private real credentials are used.
2. Existing snarkjs WASM calculator emits full WTNS. `proof-probe/src/lib.rs::read_wtns/read_r1cs` validates magic/version/section sizes, BN254 modulus, canonical values, wire/constraint bounds. `satisfied` checks count, z[0]=1 and all original constraints. `deltas` scans two complete equal-length assignments and emits unique nonzero differences, with full assignment indices.
3. `groth16_setup_dynark` creates a separate development PK/VK for exact imported matrices. `generate_updating_keys` derives domain bases, convolution weights and A/B column indexes from public PK/matrices; it also clones PK. This method does not accept toxic waste. Compatibility with an imported ordinary/snarkjs PK is not established by the probe.
4. `prove_dynark` evaluates padded A/B/C, computes quotient and full randomized A/B/C, retains proof components and r/s in Cache. `process_dynark` recomputes evaluations and fills q_a/q_b, retaining the same anchor.
5. `update_dynark` gathers A/B row changes from indexed columns; computes assignment-query and auxiliary-query terms; combines anchor projections with two nested off-diagonal cross loops and a diagonal overlap term; applies fresh proof randomization. It returns a complete proof without mutating the anchor.
6. `ordinary_vk/ordinary_proof` map points/queries to crates.io ark-groth16 0.5; ordinary verifier receives five public inputs excluding constant one. Canonical compressed artifacts support a separate process verifier with no witness/cache/reference verifier. This is not Solana's 256-byte proof encoding.
7. Existing application/program policy separately checks issuer, action digest, clock, latest root and unused action before receipt creation. No dynamic proof has been submitted to Solana in this phase. Old-root mathematical acceptance is separate from execution-current-root rejection.

## Parent-reviewed algebra and state invariants

D: define L_i interpolation basis and T=X^N−1. For satisfying row evaluations, ab−c is divisible by T. The bilinear quotient kernel is `(L_i L_j − indicator(i=j)L_i)/T` (then encoded with the proving-key scaling); the subtraction removes interpolation remainder on diagonal. This explains why the code uses both directional off-diagonal weights and separate p[i] overlap. The state-specific projection is linear in a or b, but changing the assignment alters both: cross-action recombination needs all cross terms and correct witness dependencies. No reuse across holders/actions is established.

D: the fully dynamic update's `new_accumulated_A × delta_B + delta_A × old_accumulated_B` ordering includes the newest delta_A delta_B once. Reversing which accumulator is old/new can omit or double that term. The source's local algebra is consistent with that incremental bilinear identity, but reconstruction/copy/swap correctness over sequences is untested here.

Required invariants: constant one never changes; full/instance/auxiliary index spaces are explicit; before/after assignments satisfy the same relation; cache projections/proof/blinders share one anchor; proof public values equal target generation; UK/PK/VK/reduction/domain all match; rebuilding cache has one frozen snapshot plus exactly-once corrections; swap only when reconstruction completes; a failed operation exposes no partial committed generation. Fully dynamic randomization must use independent unpredictable r/s. These were personally reviewed by the parent against source; no claim of full adaptive security theorem review is made.
