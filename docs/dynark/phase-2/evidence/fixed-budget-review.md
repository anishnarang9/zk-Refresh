# Fixed benchmark resource standard

October 11, 2026. The user requested fixed resource allowances independent of background laptop memory use. The [policy and implementation plan](../../../superpowers/plans/2026-10-11-dynark-fixed-resource-budget.md) supersedes earlier normal-pressure/quiet-swap launch gates for future performance measurements. Historical reports and frozen sources are preserved.

The active profile is `dynark-fixed-budget-v1`: **4 GiB sampled workload-tree RSS, four Rayon workers, one Rust test thread, one heavy trial at a time**, and an additional **192 MiB monitoring/reporting planning allowance**. Existing workload-specific elapsed-time, output and arithmetic ceilings remain fixed. The RSS watchdog samples every 0.2 seconds; it neither reserves RAM nor imposes a hard allocation/virtual-memory quota. The monitoring allowance is not independently RSS-enforced. Background apps may affect timing, compression and swapping; the profile does not claim isolation or average-laptop representativeness.

Admission now takes one valid noncritical host sample. Normal and warning pressure permit work; valid swap activity is recorded without changing the allowance. Critical pressure and unusable telemetry interrupt with preserved cleanup/evidence. A workload memory/time/output stop is reported separately as unable to complete within the fixed budget. No automatic retry or post-failure budget expansion is introduced.
