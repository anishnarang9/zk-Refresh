These are operation counts, not latency bounds.

Domain work is checked (`reconstruction.rs:151`). Structural capacity bounds exclude allocator/Arc headers/native/backend transient bytes and OS OOM recovery; sampled command limits independently bound the finite test run. Positive grants consume reviewed actions or report completion/error; zero grants mutate no state.

With t<b and d<=b, checked t+d permits at most one crossing. Below threshold use F(t+d)-already-completed, floored at zero; at a crossing finish old W, promote, pay one new header and do F(overshoot) minus that paid header. Background work reduces outstanding quota. Exactly-threshold freezes a header without row work. Promotion carries old-builder pending maps through the target into active maps, swaps complete physical roles, then freezes the actual target with empty pending corrections. InitialReadyAlias performs no fictitious completed reconstruction. Reversal never refunds C; named zero delta rerandomizes/advances generation while preserving distance/maps/maintenance.
